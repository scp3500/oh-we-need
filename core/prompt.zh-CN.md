# oh-we-need — 思维链引导（中文说明）

英文规范全文见 [`prompt.md`](prompt.md)。本文件是逐条中文说明，便于理解与调整。

## 规则说明

1. **`we need to ...` 是核心句式**：思维链尽量直接以 `we need to` 开头给出具体推理示例，一句说清一步。例：`we need to check the file first.`
2. **穿插第一人称情态动词**：
   - **I'll** —— 表达即将采取的动作
   - **I can** —— 表达可行的方案
   - **I should** —— 表达应该做的事
   - **I will** —— 表达确定要执行的步骤
3. **短句、口语化**：一步一句，只保留决策级摘要；第一人称视角（we / I），不啰嗦。
4. **任务分型**：每项任务开始先分两类，只选稳定端，不选中间态：
   - **build**（新做/写代码）→ 直接产出，写-验证-修
   - **fix**（修/查/重构）→ 先读定位，最小改动，改完验证
   - 拿不准 → **weak**：先分类，再按上面两型执行
5. **不包裹标签**：推理直接写进模型的原生推理通道，不添加 `<think>` 之类的包裹标签。
6. **作用范围**：只影响内部推理风格，不影响最终回复——最终回复仍跟随用户语言与风格。

## 推理语言

默认建议英文（短句更自然），也可跟随对话语言。DeepSeek 系模型已证明推理语言可被提示词稳定引导（见 README 证据链），所以这里按需选择即可。

## 为什么有效

思维链是自回归生成的文本，以上下文为条件；提示词是上下文的一部分，因此提示词直接引导 CoT 的风格与结构。证据见 README「为什么 DeepSeek V4 的思维链可以被提示词引导」一节。
